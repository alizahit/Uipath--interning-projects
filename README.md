# 🚀 UiPath Internship Projects Repository

This repository contains a collection of enterprise-grade **Robotic Process Automation (RPA)** projects developed during my internship. The primary goal of these projects is to automate complex, real-world business processes, demonstrating proficiency in scalable bot architecture and seamless third-party system integrations.

## 🛠️ Technologies & Integrations Used

The projects within this repository strictly adhere to enterprise automation standards, heavily utilizing the following frameworks and platforms:
* **UiPath REFramework (Robotic Enterprise Framework):** Used as the foundational architecture for all projects to ensure robust exception handling, scalability, and state machine transitions.
* **Salesforce Integration:** Deep integration with Salesforce (via UiPath Integration Service and APIs) to automate CRM workflows such as Lead qualification, scoring, and automated contract generation.
* **Orchestrator Queues & Assets:** Standardized use of UiPath Orchestrator for transaction management, credential storage, and dynamic configuration loading.
* **Document Processing & Email:** Automated generation of Word/PDF documents and standardized email dispatching using Microsoft Office/Google Workspace activities.

## 📂 Project Directory

Below is a summary of the automated solutions included in this repository:

### 1. `My-SalesforceAutomaticContract-001`
Automates the end-to-end process of generating client contracts dynamically from Salesforce transaction data, updating CRM records, and distributing the finalized documents via email.
### 2. `My-salesforceDemoRequest-001`
Automates the Salesforce Lead Qualification workflow by extracting new lead data, performing programmatic lead scoring, and automatically updating lead statuses within the CRM.
### 3. `NativeDigital_Bootcamp_PazarAraştırması_001`
An automated market research bot that systematically scrapes, aggregates, and processes web data to generate structured insights for bootcamp market analysis.
